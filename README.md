# COVID-19 SQL & Python Analysis

SQL fundamentals and data analysis using a real-world COVID-19 dataset.

## Project Overview

Step-by-step SQL practice project analyzing global pandemic data. The notebook guides through core SQL concepts with hands-on examples.

## Lessons Covered

1. Database setup with SQLite
2. Basic SELECT queries
3. Filtering with WHERE clauses
4. Aggregation functions (COUNT, SUM, AVG, MIN, MAX)
5. Grouping and HAVING clauses
6. Sorting with ORDER BY
7. SQL JOINs to combine tables
8. Subqueries and nested queries
9. Window functions (ROW_NUMBER, RANK, DENSE_RANK)
10. Data visualization with matplotlib

## Skills

SQL (SELECT, WHERE, GROUP BY, JOIN, window functions), Python (pandas, sqlite3), data visualization.
